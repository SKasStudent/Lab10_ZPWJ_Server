=====================================================
 LAB5 - URUCHOMIENIE I TESTOWANIE (CachyOS / Linux)
=====================================================

--- 1. INSTALACJA (jednorazowo) ---

sudo pacman -S docker docker-compose jdk-openjdk maven jq
sudo systemctl enable --now docker.service
sudo usermod -aG docker $USER
(teraz wyloguj sie i zaloguj ponownie albo zrestartuj komputer)

docker run --rm hello-world
java -version
archlinux-java status


--- 2. URUCHOMIENIE (w folderze Lab5_zpwj) ---

docker compose up -d
docker ps
mvn spring-boot:run

(czekaj na "Tomcat started on port 8080", testy rob w drugim terminalu)


--- 3. KLIENCI ---

Odczyt wszystkich:
curl -s http://localhost:8080/api/clients | jq

Odczyt jednego:
curl -s http://localhost:8080/api/clients/1 | jq

Dodanie:
curl -i -X POST http://localhost:8080/api/clients -H "Content-Type: application/json" -d '{"name":"Jan","surname":"Kowalski","email":"jkowa@email.com","phone":"444444444"}'

Aktualizacja:
curl -i -X PUT http://localhost:8080/api/clients/1 -H "Content-Type: application/json" -d '{"name":"Szymon","surname":"Kasperczuk","email":"nowy@email.com","phone":"999999999"}'

Oznaczenie jako nieaktywny:
curl -i -X PATCH http://localhost:8080/api/clients/inactive/2

Trwale usuniecie:
curl -i -X DELETE http://localhost:8080/api/clients/3

Sprawdzenie usuniecia (powinno byc 404):
curl -i http://localhost:8080/api/clients/3


--- 4. DREWNO ---

Odczyt wszystkich:
curl -s http://localhost:8080/api/wood | jq

Odczyt jednego:
curl -s http://localhost:8080/api/wood/1 | jq

Dodanie:
curl -i -X POST http://localhost:8080/api/wood -H "Content-Type: application/json" -d '{"species":"Pine","price":7.50,"quantity":200}'

Aktualizacja:
curl -i -X PUT http://localhost:8080/api/wood/1 -H "Content-Type: application/json" -d '{"species":"Oak","price":12.00,"quantity":80}'

Oznaczenie jako niedostepne:
curl -i -X PATCH http://localhost:8080/api/wood/unavailable/2

Trwale usuniecie:
curl -i -X DELETE http://localhost:8080/api/wood/3

Sprawdzenie usuniecia (powinno byc 404):
curl -i http://localhost:8080/api/wood/3


--- 5. OCZEKIWANE KODY ODPOWIEDZI ---

GET    -> 200
POST   -> 201
PUT    -> 200
PATCH  -> 204  (potem GET pokazuje "active": false / "available": false)
DELETE -> 204  (potem GET na to id zwraca 404)


--- 6. PODGLAD BAZY ---

docker exec -it Lab5 psql -U zpwj -d tartak -c "SELECT * FROM clients;"
docker exec -it Lab5 psql -U zpwj -d tartak -c "SELECT * FROM wood;"


--- 7. RESET BAZY ---
(gdy przy starcie jest blad "no unique or exclusion constraint matching the ON CONFLICT")

docker compose down -v
docker compose up -d


--- 8. ZATRZYMANIE ---

Ctrl+C w terminalu z aplikacja
docker compose down
